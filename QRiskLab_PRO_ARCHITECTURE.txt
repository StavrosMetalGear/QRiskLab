QRiskLab Pro — Professional Hybrid Python/C++ Architecture
===========================================================

Goal
----
Transform QRiskLab from a C++ command-line project into a hybrid Python/C++ quantum finance and quantum computing platform.

Core identity:
Python = research layer, dashboards, AI/ML, quantum libraries, finance workflows.
C++ = high-performance engine for Monte Carlo, risk, option pricing, and future circuit/statevector simulation.

Main Modules
------------

1. cpp_core
   Purpose: fast numerical engine.
   First functions:
   - Monte Carlo path simulation
   - VaR / CVaR calculations
   - Black-Scholes pricing
   - benchmark timers
   Later:
   - statevector simulator
   - sparse Hamiltonian operations
   - circuit stepping

2. bindings
   Purpose: pybind11 bridge from Python to C++.
   Python should be able to call:
   - qrisklab_cpp.run_monte_carlo(...)
   - qrisklab_cpp.calculate_var(...)
   - qrisklab_cpp.price_option(...)
   - qrisklab_cpp.simulate_statevector(...)

3. python/qrisklab/finance
   Purpose: quant finance workflows.
   Include:
   - market data loading
   - returns and covariance
   - portfolio optimization
   - VaR / CVaR
   - option pricing
   - classical vs C++ comparison

4. python/qrisklab/quantum
   Purpose: quantum computing workflows.
   Include:
   - Qiskit circuits
   - PennyLane QAOA / variational circuits
   - QuTiP open quantum systems
   - quantum portfolio optimization demos

5. python/qrisklab/qml
   Purpose: quantum machine learning.
   Include:
   - hybrid PyTorch + PennyLane models
   - quantum kernels
   - small classifiers

6. python/qrisklab/api
   Purpose: FastAPI backend.
   Include endpoints:
   - /health
   - /risk/monte-carlo
   - /risk/var
   - /portfolio/optimize
   - /quantum/qaoa
   - /benchmark/python-vs-cpp

7. python/qrisklab/dashboards
   Purpose: Streamlit app.
   Main pages:
   - Monte Carlo Risk
   - Portfolio Optimization
   - QAOA Portfolio
   - QuTiP Quantum Dynamics
   - Python vs C++ Benchmarks

Professional Build Order
------------------------

Phase 1: Restructure current C++ project
- Create cpp_core/include and cpp_core/src.
- Move current simulator/risk code into cpp_core.
- Keep a CLI app under cpp_core/apps/qrisklab_cli.cpp.

Phase 2: Add Python package
- Create python/qrisklab.
- Add requirements.txt.
- Implement pure Python risk and portfolio functions first.

Phase 3: Add dashboard
- Add Streamlit pages.
- First page: Monte Carlo Risk.
- Second page: Portfolio Optimization.

Phase 4: Add pybind11
- Create bindings/pybind_module.cpp.
- Expose C++ Monte Carlo engine to Python.
- Add benchmark page: Python vs C++.

Phase 5: Add quantum
- Add Qiskit circuit demos.
- Add PennyLane QAOA portfolio optimizer.
- Add QuTiP dynamics demo.

Phase 6: Add API and reports
- Add FastAPI backend.
- Add HTML/PDF reports.
- Save experiment results.
