# QRiskLab GUI Roadmap

## Introduction
QRiskLab will use a Streamlit-first GUI because Streamlit already exists in the project. The purpose of the GUI is to make QRiskLab usable as an interactive quantum finance and risk analysis application, connecting finance, portfolio, quantum, API, and educational theory features.

## Planned GUI Sections
- Home
- Information / Theory
- Option Pricing
- Risk Analysis
- Portfolio Tools
- Quantum State Tools
- Quantum Algorithms
- API / Developer Tools

## Information / Theory Widget
The Information / Theory widget will explain what QRiskLab does, covering topics such as:
- Monte Carlo simulation
- Geometric Brownian Motion
- European option pricing
- Discounted expected payoff
- VaR and CVaR
- Portfolio risk
- Quantum states
- Amplitudes and probabilities
- Quantum amplitude estimation
- Assumptions and limitations

## Phased GUI Implementation Steps
1. GUI skeleton
2. Navigation
3. Information / Theory widget
4. Option pricing page
5. Risk analysis page
6. Portfolio tools page
7. Quantum state tools page
8. Quantum algorithms page
